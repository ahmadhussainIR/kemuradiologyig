# KemRad Website

Static GitHub Pages website for KemRad, the KEMU Radiology Interest Group.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. In GitHub, open `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a public URL after the first deployment finishes.

## Edit the site

- Main page: `index.html`
- Announcements page: `announcements.html`
- Membership form page: `membership.html`
- Styles: `styles.css`
- Small mobile-menu script: `script.js`
- Hero image: `assets/hero-radiology-learning.png`
- Logo: `assets/kemrad-logo.svg`
- Founder portrait crop: `assets/ali-husnain-founder.png`
- President portrait: `assets/ahmad-hussain-president.jpg`

The hero image is an illustrative project asset generated for this website. The site links to the public Instagram, X, Linktree, RadMed Review Instagram, KEMU, and radiology resource pages, but does not embed social posts or require any external build tools. The contact form opens a pre-filled email to `kemuradiologyig@gmail.com`. The membership form uses FormSubmit so applications can be emailed to `kemuradiologyig@gmail.com` from GitHub Pages.
